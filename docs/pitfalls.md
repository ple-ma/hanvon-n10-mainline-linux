# 坑清单

踩过的坑，按"会浪费你多少时间"排序。细节都在 journey.md 里。

## 显示

- 帧缓冲是 1872×1404 横屏布局，设备竖着用。忘了坐标变换会得到一块全黑或者全花的屏幕。
  画布旋转写入，输入坐标反向映射，两边都要做。
- 屏幕左右出现错位条纹时，别死磕行跨度和面板时序。往消隐区想：多余的扫描线落在了帧缓冲
  外的相邻行上，panel-simple 的 vtotal 补偿能修。实测值 5。
- 墨水屏全刷闪黑是正常物理现象，不是 bug。频繁小更新用局部刷新，大变化才全刷。
- 刷新模式对体感影响巨大。同一个界面 mode 2 和 mode 4 能差出一个档次，选 2。

## 刷机

- BCB 救砖流程（写 bootloader_message 进 loader）比拆机短接友好多了，但刷坏 boot 分区
  时它也救不了你。动 boot 之前先备份。
- 打包 boot.img 时别忘了 initramfs 里要放两样东西：墨水屏波形文件和 WiFi 固件。缺前者白屏，
  缺后者没网。

## 电磁笔

- 笔的数据在 uart5 上（57600，7 字节定长包），不在 I2C 上。原厂的闭源模块走的哪条路不重要，
  它的 sysfs 只是个内存变量，改了没效果，别在这上面浪费时间。
- 四角校准时每角要停够时间取中位数，手持笔的抖动比想象中大。
- uinput 注册的设备名字要和 GUI 里找设备用的名字一致（hanvon_pen），不然 GUI 永远找不到笔。

## 输入与终端

- uinput 注入和直写 /dev/fb0 都要 root。以普通用户跑 GUI 会得到一堆不报错但没效果的调用。
- 屏幕键盘的按键注入到 tty 之后，打字速度跟终端回显刷新绑在一起。别在按键回调里刷新屏幕，
  会闪到怀疑人生。让终端自己回显。
- pyte 渲染要用等宽字体，且要求"拉丁宽度恰好是汉字宽度的一半"，否则终端网格对不齐。
  中文环境推荐 Maple Mono NF CN 这类三合一字体（等宽、中文、符号字形全），缺字形会显示方块。

## 电源

- 休眠唤醒后整屏泛白，先查 PMIC（fp9931）驱动在不在，别怀疑屏幕。驱动缺失时电源时序靠默认值
  硬扛，唤醒后状态恢复不了。
- 电磁笔和屏幕共用部分电源域，早起排查时被"笔相关时钟门控"带偏过一次，实际根因在 DCDC 序列。

## 音频

- rk817 codec 的声卡不出现时，报错信息不会告诉你任何事。如果驱动都在但声卡没有，查
  rk8xx-core 给 codec 子设备挂 of_node 的那行代码。

## WiFi

- brcmfmac43456 的固件加载发生在内核 probe 阶段（开机 1 秒内），那时根分区还没挂载。
  固件放 rootfs 里等于没放，必须进 initramfs。
